Documento de arquitetura · v1.0

CultiveAI

Plataforma para análise de pastagens degradadas combinando dados NDVI do Google Earth Engine com interpretação por IA generativa via Gemini. Quatro diagramas vetoriais para artigos, apresentações e teses.

Backend
FastAPI · SQLAlchemy
Frontend
Vue 3 · Vite
Dados
PostgreSQL 16
Deploy
Docker · Nginx
FIG. 01

Visão de containers e integrações

Topologia de produção orquestrada via Docker Compose. O navegador acessa Nginx, que serve a SPA e faz proxy de /api/v1 para o FastAPI. O backend conversa com PostgreSQL internamente e com dois serviços externos: Google Gemini e Google Earth Engine.

FIG. 02

Estrutura do backend em camadas

Arquitetura do backend FastAPI organizada em cinco camadas: Entry inicializa, API orquestra rotas, Domínio contém regra de negócio (Schemas, CRUD, Services), Dados mapeia o banco via ORM, Infra provê configuração e migrações. Cada camada conhece apenas as inferiores.

FIG. 03

Estrutura do frontend

Single Page Application Vue 3 com roteamento por guards de autenticação. Views consomem componentes reutilizáveis (mapa, relatório, exportação PDF) e centralizam toda chamada HTTP em ApiService com interceptor JWT.

FIG. 04

Fluxo de uma análise NDVI

Caso de uso completo em 12 passos: o usuário seleciona uma propriedade, o sistema obtém a série temporal NDVI no Earth Engine, envia ao Gemini para interpretação textual, persiste o resultado em PostgreSQL e devolve o relatório à interface.
